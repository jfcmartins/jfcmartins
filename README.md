## What I'm building

**[Limen](https://github.com/limen-dev/limen)** is an open-source, self-hosted, identity-aware access layer for infrastructure, written in Rust.

Access to infrastructure is typically scattered across per-system users and credentials, with no unified model for identity, access control and auditability.

Limen gives humans, bots and AI agents one identity and audit layer across SSH, databases, Kubernetes, message brokers and internal apps, with short-lived credentials and auditable sessions.

I'm the creator of Limen, which is in active development.

```sh
brew install limen-dev/tap/limen
```

- 📖 [Documentation](https://limen-dev.github.io/limen)
- 🧩 Ecosystem:
  - [terraform-provider-limen](https://github.com/limen-dev/terraform-provider-limen): Terraform and OpenTofu provider for managing resources, roles and bots
  - [setup-limen](https://github.com/limen-dev/setup-limen): GitHub Action that logs a workflow in as a bot using its OIDC token, with no stored secret
  - [homebrew-tap](https://github.com/limen-dev/homebrew-tap): Homebrew tap for installing the CLI

More about my work is on [jorgemartins.dev](https://jorgemartins.dev).
